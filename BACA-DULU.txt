NomNom - Web Pemesanan & Transaksi Online (Fullstack PHP & MySQL Database)

PANDUAN MENGHUBUNGKAN KE DATABASE MYSQL (XAMPP / LARAGON):
1. Buka XAMPP Control Panel, lalu jalankan (Start) modul Apache dan MySQL.
2. Pindahkan atau salin folder `nomnom-web` ini ke dalam folder `htdocs` XAMPP:
   (Misal: C:\xampp\htdocs\nomnom-web\)
3. Buka browser dan masuk ke phpMyAdmin:
   http://localhost/phpmyadmin/
4. Buat Database Baru:
   - Nama database: nomnom_db
   - Klik tombol "Create / Buat".
5. Impor Tabel Database:
   - Klik tab "Import" di phpMyAdmin.
   - Pilih berkas `database.sql` yang ada di dalam folder nomnom-web.
   - Klik "Go / Kirim".
   (Database akan otomatis terisi tabel: admin, produk, pesanan, detail_pesanan, dan pengaturan_toko).
6. Buka Website di Browser:
   http://localhost/nomnom-web/

AKSES LOGIN ADMIN (TERSIMPAN DI DATABASE MYSQL):
- Username Default : admin
- Password Default : admin123
(Tersimpan secara aman di tabel `admin` dengan enkripsi password_hash).

STRUKTUR FILE (SEMUA DI DALAM 1 FOLDER UTAMA):
- index.html     : Tampilan antarmuka website, form checkout, modal struk, dan dashboard admin
- style.css      : Styling CSS responsive, dark/light theme, progress tracking, dan print view
- script.js      : Logika JavaScript yang menghubungkan frontend ke file-file PHP
- database.sql   : Skrip struktur tabel database dan data awal (impor ke phpMyAdmin)
- koneksi.php    : File koneksi PDO MySQL & response JSON
- auth.php       : Login admin, cek sesi, ganti password, & logout
- pesanan.php    : Menyimpan pesanan pembeli ke tabel `pesanan` & `detail_pesanan`, serta update status pesanan
- katalog.php    : Mengambil data menu dari tabel `produk`, tambah/edit menu, toggle status stok, & hapus menu
- pengaturan.php : Pengaturan buka/tutup PO dan kontak toko
- BACA-DULU.txt  : Panduan ini
